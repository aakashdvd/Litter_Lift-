## [1.0.0]

### Added
- Litter reporting with photo upload and automatic geolocation.
- Cleanup status tracking dashboard for admins.
- Community leaderboard for active contributors.
- Interactive map view of reported litter locations.
- Email notifications to service centers on new reports.
- Recycling pickup requests with nearest-center matching.
- Stripe-powered donation flow.
- Vercel deployment configuration.

### Fixed
- Google Maps deep link format for mobile devices.
- Error handling for failed API requests.
- Responsive layout issues on mobile devices.
- `httpOnly` flag enforced on JWT cookies.
